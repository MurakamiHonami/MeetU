# ADR-002: Email/Password 認証への移行

## Status

Accepted

## Context

初期設計（`docs/archive/design-legacy.md`）では LINE LIFF + LINE Login による認証を想定していた。
MeetU は Web アプリとして独立して動作する必要があり、LINE 依存を外すことで開発・テスト・デプロイが簡素化される。

## Decision

- **認証方式**: Email + Password（bcrypt ハッシュ）
- **セッション**: JWT Access Token（短期）+ Refresh Token（KV 保存、HttpOnly Cookie）
- **モック認証**: `mock_<userId>` トークンは **`APP_ENV=local` のみ** 有効（staging / production では拒否）

## Consequences

- LINE Messaging API / LIFF SDK は不要
- フロントは React + React Router の通常 Web アプリ
- ローカル開発は `wrangler dev` + Vite proxy で完結
