# ADR-003: Cloudflare Workers 静的アセットによるフロント配信

## Status

Accepted

## Context

当初は Cloudflare Pages を想定していたが、API と同様に Workers 上で統一することでデプロイ・ルーティング・カスタムドメイン管理を一本化できる。

## Decision

- **フロントエンド**: Vite build → Workers Static Assets（`wrangler.staging.json` / `wrangler.production.json`）
- **SPA ルーティング**: wrangler の `assets.not_found_handling: "single-page-application"` を使用
- **`public/_redirects` は不使用**（Pages 向けの遺物）

## 環境別 Worker 名

| 環境 | Worker | URL |
|------|--------|-----|
| Staging | `meetu-web-staging` | https://meetu.staging.ruxel.net |
| Production | `meetu-web` | https://meetu.ruxel.net |

## Consequences

- デプロイは `just deploy-staging-frontend` / `just deploy-production-frontend`
- `VITE_API_BASE_URL` を build 時に注入（`.env.staging` / `.env.production`）
- API CORS は `CORS_ORIGINS` でフロント URL を許可
