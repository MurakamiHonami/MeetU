# プロジェクトの目的
- 日本国内のオタク層に、サービスの価値と信頼できる根拠を伝える
- サイトで最も優先する行動は「カードの登録」
- サービス内容や操作の分かりやすさと、利用者に安心感を与えること

# 想定利用者
- 主な利用者：［20~30代・アニメやアイドルが好き・グッズ交換やイベント参加を頻繁に行っている層］
- 読者が不安に思うこと：［安全に取引できるか・マッチする相手が見つかるか・操作方法］
- 利用者に伝えたいこと：［安心して、他のサービスよりより良い取引ができるサービス］


# デザイン方針
- 配色、書体、余白には、このサービスでそうする理由を持たせる
- グラデーション、カード3枚並び、過度な角丸を初期設定にしない
- 写真を仮画像のまま完成扱いにしない
- スマートフォンでも本文を16px未満にしない


# 完成の条件
- 375px、768px、1440pxで表示を確認する
- すべてのリンク、ボタン、フォームを実際に操作する
- コンソールエラー、横スクロール、文字切れがないことを確認する
- 実在しない実績、数値、顧客名を公開しない
